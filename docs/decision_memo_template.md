# Decision memo template

## Question and recommendation

State the engineering question and the conditional recommendation in a short paragraph. Include the condition that would reverse the recommendation. Do not claim operational authority or reserve certification from a learning case.

## Evidence

Summarize the relevant observations and calculations. Distinguish actual data from synthetic observations, model estimates and assumed inputs. Cite sources and link immutable run artifacts.

## Interpretation

Explain the physical mechanism, not just the direction of a plot. Identify competing explanations, parameter non-uniqueness and any operating constraint that changes what the data can reveal.

## Uncertainty and limits

Separate data uncertainty, numerical error, parameter uncertainty and model-structure uncertainty. State what was not measured or represented. Declare probability conventions and avoid unsupported precision.

## Next measurement or action

Identify the most useful additional observation and how it could discriminate between alternatives. For a synthetic study, frame the result as a methodological lesson rather than a field instruction.

## Reproducibility and review

Record run ID, input/config/source hashes, software version, reference comparison, checks actually executed, review findings and unresolved issues.
