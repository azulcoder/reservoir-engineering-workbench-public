# Scope of licensing

The repository licence covers original repository code and text only. Referenced
books, papers, software, datasets, trademarks and third-party materials retain
their own licences and notices. No third-party book, simulator binary, raw field
dataset, or software licence file is redistributed here.

Keep original dataset/source acknowledgements and legally required notices when
adding material. Do not apply the repository's MIT licence to imported datasets.
No endorsement by a data provider, software vendor or employer is implied.

# NIST Standard Reference Data

The reference fluid properties this project uses as an independent PVT oracle come from
the NIST Chemistry WebBook, SRD 69. They are not redistributed here. NIST SRD is
copyrighted under a statutory exception (Standard Reference Data Act, Public Law
90-396), and the evidence retrieved for this project does not establish that citation
alone permits redistributing an extract, so the project publishes metadata and
acquisition instructions instead of values. This is a conservative publication decision,
not an adjudication of copyright exceptions. See docs/release/PUBLIC_DATA_POLICY.md for
the decision and its evidence, and data/reference/README.md for what the metadata
covers.

Cite NIST Chemistry WebBook, SRD 69, together with the per-species reference equation
recorded in data/reference/MANIFEST.json, wherever these values or results derived from
them are reported.
